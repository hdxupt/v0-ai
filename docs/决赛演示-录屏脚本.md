## 分镜脚本（4 段 × 各 15s）

### 0–15s｜客观题批改
- 画面：教师端打开一份**客观题**作业 → AI 批改结果。
- 重点给到：错题旁的**标签**（题号+对错），做对的直接过。
- 叠加字幕：`客观题：自动判分，题目旁的演算过程自动忽略`
- 口播：「老师打开作业，AI 已经判好每道客观题的对错，旁边的演算草稿被自动隔绝，不干扰判断。」

### 15–30s｜主观题批改
- 画面：切一份**主观题/作文** → 出错那一行的**红色波浪下划线** + 五维雷达 + 完整评语。
- 叠加字幕：`主观题：错处精准定位 + 五维诊断 + 完整评语`
- 口播：「主观题这边，AI 用波浪线标出错处，给出五个维度的诊断和完整评语，老师只需审核，不用从零批改。」

### 30–45s｜量化数据看板（/impact 特写）
- 画面：打开 `/impact`，**滚动到速度卡 + 工时卡**，给数字特写。
- 重点给到：`人工 5分钟 → AI 25秒`、`12× 提升`、`¥0.18/份`、`累计已节省工时`（数据库实时）。
- 口播：「效率上，单份从人工 5 分钟降到 25 秒，约 12 倍提升，成本不到两毛。这些是平台真实运行统计出来的，不是 PPT 数字。」

### 45–60s｜育人闭环（变式题）
- 画面：学生端 → 错题 → **一键生成变式题** → 答题 → 判对错。
- 叠加字幕：`从"知道错"到"学会了"`
- 口播：「最后是闭环——针对错题，AI 自动生成同知识点的变式题，让学生当场练、当场巩固。这就把批改变成了真正的学习闭环。」
